# Outlier (personal)

Outlier is a desktop app for Windows that one person uses on their own computer. It turns what they type, drop in or
connect into personal indexes and shows only what is unusual.

This page exists because Google asks every app that uses Google sign-in to have a home page and a privacy policy.
The Google Cloud project and sign-in client behind "Outlier (personal)" are used by one person only, for their own
calendar and mail, on their own computer.
